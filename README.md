# Lio — Learn It Out

Lio is an adaptive technology-learning publication: simple explanations, useful projects, visual thinking, and a feed that learns what each reader should learn next.

## MVP

- Static, fast website with no backend dependency
- Beginner-first technology content
- Lightweight onboarding stored locally in the browser
- Local learning progress and recommendation signals
- Structured article metadata for a future knowledge graph
- GitHub Pages deployment

## Content philosophy

Lio is not an AI-generated news dump. Research and current technology are raw material. Every article should leave the reader knowing, doing, or understanding something useful.

## Project memory

The durable project decisions live in [`PROJECT.md`](PROJECT.md). When continuing Lio in a new conversation, use that file as the source of truth so the project does not depend on chat context.

## Local preview

Open `index.html` directly for a quick preview, or serve the repository with any static HTTP server.

## Deployment

GitHub Pages can publish the repository through the included GitHub Actions workflow.
