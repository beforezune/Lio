The word that needed help from every other word — attention

A transformer does not treat every piece of context as equally useful. Attention gives it a learned way to compare, weight, and combine information from different tokens.

LIO · LEARN IT OUT   /   FOLLOW ONE TOKEN THROUGH THE MECHANISM

Imagine Sana is reading this sentence:

“The trophy didn't fit in the suitcase because it was too large.”

She reaches the word it.

What does it mean?

Her brain quietly checks the surrounding sentence.

The trophy is large.

The suitcase is also large enough to be discussed.

But the phrase “didn't fit ... because it was too large” makes the trophy the stronger interpretation.

Sana just performed a contextual routing operation without thinking about it.

Attention gives a neural network a mathematical mechanism for deciding which contextual information should contribute more to a representation.

The problem before attention

A token by itself is often ambiguous.

Consider:

river bank

investment bank

The token bank is the same string, but its useful representation depends on its context.

A language model therefore needs more than a dictionary lookup. It needs a way for representations to interact.

So give each token three roles

For the simplified self-attention mechanism, each token representation is projected into three vectors:

  • Query: what this position is looking for.
  • Key: what this position offers for matching.
  • Value: the information that can be passed onward if this position is useful.

These are not three human-readable labels stored inside the model. They are learned vector transformations.

The names are simply a useful way to remember the computation.

Step one: compare the query with the keys

Suppose the token we care about creates a query vector.

The model compares that query with the key vector for each relevant token.

A common implementation uses a scaled dot product:

score = Query · Key

A larger score means the two vectors are more aligned under the learned representation.

At this point we have scores, not yet a final mixture.

Step two: turn scores into weights

The scores are transformed with softmax, producing normalized weights.

For a toy example, imagine the model gets:

trophy    0.72

suitcase  0.18

because   0.07

the      0.03

The numbers are illustrative, not a literal measurement of human attention.

They represent how strongly the current position weights those value vectors for this particular computation.

Step three: mix the values

Now the model uses those weights to calculate a weighted combination of the corresponding value vectors.

Query + Keys

Compare the current position with other positions.

Scores → Weights

Convert those comparisons into normalized mixing weights.

Weights × Values

Combine information from the context according to those weights.

The result becomes a new representation for the current position.

That is the core attention operation.

Why call it “self”-attention?

Because the queries, keys, and values come from the same sequence.

The tokens are effectively looking at other tokens in that sequence to construct richer representations.

In a causal language model, there is an important restriction: when predicting the next token, a position cannot use information from future tokens that would not actually be available.

Now imagine doing this for every token

The same mechanism runs across positions.

And modern transformers use multi-head attention, which lets the model perform several attention computations in parallel with different learned projections.

A useful intuition is not “one head finds grammar and another finds facts” as a guaranteed rule. Instead, think of multiple learned routing patterns that can capture different relationships useful to the model.

The formula is less scary than it looks

A common scaled dot-product attention expression is:

Attention(Q, K, V) = softmax(QKᵀ / √dₖ)V

Read it from left to right:

  • QKᵀ: compare queries with keys.
  • / √dₖ: scale the scores for numerical stability.
  • softmax: turn scores into normalized weights.
  • × V: use those weights to mix the values.

The equation is simply the precise version of the story you just followed.

Attention is powerful, but don't give it magical powers

An attention weight is not a perfect explanation of what a model “understands.”

Attention is one mechanism inside a much larger architecture.

A model can use attention effectively and still hallucinate, reason incorrectly, or fail to follow a constraint.

The safest mental model is:

attention is learned information routing, not a tiny human mind looking at words.

Why this changed modern AI

Once transformers could efficiently transform sequences using attention, researchers had an architecture that scaled well with modern hardware and large datasets.

The 2017 Transformer work helped establish this architecture as a foundation for modern language models, and the same family of ideas spread into vision, audio, multimodal systems, and other domains.

You now have the useful version

  • Attention lets token representations interact with contextual information.
  • Queries, keys, and values are learned projections used by the attention computation.
  • Query-key comparisons produce scores that become normalized weights.
  • Those weights determine how value vectors are mixed into the output.
  • Self-attention operates within the sequence; causal attention restricts access to future positions when needed.
  • Multi-head attention provides multiple learned projections and routing patterns.
  • Attention is a mechanism, not a guarantee of understanding.
