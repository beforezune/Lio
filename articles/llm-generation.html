LLM FROM SCRATCH · 09 · GENERATION · 18 MIN READ

The model predicts a distribution. Generation decides what to do with it.

Training learns next-token probabilities. Inference repeatedly turns those probabilities into choices and feeds the chosen token back into the model.

Lio Learning Path · Intermediate

The autoregressive loop

context = prompt
for step in range(max_new_tokens):
    logits = model(context[:, -block_size:])
    next_logits = logits[:, -1, :]
    probs = F.softmax(next_logits, dim=-1)
    next_token = torch.multinomial(probs, 1)
    context = torch.cat((context, next_token), dim=1)

One forward pass predicts the next token. The selected token becomes part of the next context. Repeat.

Greedy decoding

The simplest choice is the token with the highest probability:

next_token = torch.argmax(probs, dim=-1, keepdim=True)

This is deterministic but can become repetitive because it always takes the local maximum.

Temperature

Temperature rescales logits before softmax:

scaled = logits / temperature
probs = F.softmax(scaled, dim=-1)

Lower temperature makes the distribution sharper. Higher temperature makes it flatter. Temperature changes randomness; it does not magically add knowledge to the model.

Top-k

Top-k sampling keeps only the k highest-scoring tokens and removes the rest before softmax.

values, indices = torch.topk(logits, k)
filtered = torch.full_like(logits, float('-inf'))
filtered.scatter_(1, indices, values)

Top-p

Nucleus sampling instead keeps the smallest set of tokens whose cumulative probability reaches p. It adapts the candidate set to the shape of the distribution.

For a tiny educational model, top-k is easier to implement and visualize. Once that works, top-p is a useful extension.

Why generation can fail even when loss looks good

Cross-entropy is an average training objective. Generation is a sequential process: an early bad choice becomes part of the next context and can push later predictions into unfamiliar territory. Sampling also changes behavior.

Stopping

Real generation often stops at an end-of-sequence token, a maximum token count, or a system-defined stopping condition. A character-level teaching model may simply generate a fixed number of tokens.

Experiment

Generate the same prompt at temperatures 0.5, 0.8 and 1.2. Save several samples. Compare repetition, diversity and coherence. Do not decide from one sample.

Inference efficiency

The simple loop recomputes the entire context on every step. Production Transformers use a key-value cache so previous attention keys and values can be reused. That optimization changes inference cost dramatically without changing the conceptual autoregressive process.

Training teaches the distribution. Decoding chooses a path through that distribution.
