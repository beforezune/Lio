LLM FROM SCRATCH · 06 · TRANSFORMER BLOCK · 24 MIN READ

The Transformer block is a small machine repeated many times.

Attention routes information between positions. The MLP transforms each position. Residual connections preserve a stable stream, and normalization keeps the computation well behaved.

Lio Learning Path · Intermediate
Learning goal

Assemble multi-head attention, an MLP, LayerNorm and residual connections into a GPT-style block, then stack blocks into the core of a language model.

Think of the hidden state as a stream

At the start of the Transformer, each position has a vector of width C. We will call the whole tensor x, with shape (B,T,C).

A block does not need to replace that representation with a completely new one. Instead, it can add useful updates to the existing stream.

x = x + attention_update
x = x + mlp_update

This residual structure is one of the most important engineering ideas in deep Transformers.

LayerNorm: stabilize each position

Layer normalization normalizes features within each token representation and applies learned scale and bias. In a pre-norm block, normalization happens before the attention or MLP sublayer.

self.ln1 = nn.LayerNorm(n_embd)
self.ln2 = nn.LayerNorm(n_embd)

x = x + self.attn(self.ln1(x))
x = x + self.mlp(self.ln2(x))

The exact normalization placement differs between architectures. Our goal is not to claim one universal Transformer formula; it is to build a clean GPT-style baseline.

Attention handles communication

Self-attention allows one position to read information from earlier positions. After multi-head attention, each token has a richer contextual representation.

x:                 (B,T,C)
ln1(x):            (B,T,C)
attention output:  (B,T,C)
residual result:   (B,T,C)

The fact that the shape returns to (B,T,C) is what makes the residual addition possible.

The MLP handles transformation

After attention has mixed information, the model applies a feed-forward network independently at each position. A common educational version expands the width by four:

self.mlp = nn.Sequential(
    nn.Linear(C, 4*C),
    nn.GELU(),
    nn.Linear(4*C, C),
    nn.Dropout(dropout),
)

For an input of shape (B,T,C), the first linear layer produces (B,T,4C), GELU preserves that shape, and the second layer returns to (B,T,C).

Notice the division of labor. Attention mixes information across positions. The MLP does not move information between tokens; it transforms the features at each position.

Why residual connections help

Imagine stacking dozens of transformations where every layer must rebuild the entire representation. Optimization would have a difficult job. A residual block instead learns an update:

new_x = old_x + learned_update

The identity path gives gradients a direct route through the network and lets layers specialize in corrections rather than full reconstruction.

One complete block

class Block(nn.Module):
    def __init__(self, n_embd, n_head, block_size, dropout=0.0):
        super().__init__()
        self.ln1 = nn.LayerNorm(n_embd)
        self.attn = MultiHeadAttention(
            n_embd, n_head, block_size, dropout
        )
        self.ln2 = nn.LayerNorm(n_embd)
        self.mlp = nn.Sequential(
            nn.Linear(n_embd, 4*n_embd),
            nn.GELU(),
            nn.Linear(4*n_embd, n_embd),
            nn.Dropout(dropout),
        )

    def forward(self, x):
        x = x + self.attn(self.ln1(x))
        x = x + self.mlp(self.ln2(x))
        return x

Stack depth

self.blocks = nn.ModuleList([
    Block(n_embd, n_head, block_size, dropout)
    for _ in range(n_layer)
])

for block in self.blocks:
    x = block(x)

Depth is now a parameter. If n_layer=6, the representation passes through six copies of the same architecture, each with its own learned parameters.

What each layer can change

The first blocks may learn relatively local transformations. Deeper blocks can build on representations already enriched by earlier blocks. We should be cautious about assigning clean semantic roles to individual layers, though: the computation is distributed and the learned behavior depends on the training data.

The language-model head

After the final block, normalize once more and project from model width C to vocabulary size V:

x = self.ln_f(x)
logits = self.lm_head(x)

# x      : (B,T,C)
# logits : (B,T,V)

At each position, the final vector becomes one score for every possible next token.

Those scores are called logits because they are not probabilities yet. The training loss can consume them directly; softmax is conceptually useful for understanding the distribution and is applied explicitly when sampling.

The full forward path

idx                 # (B,T)
  ↓
token + position    # (B,T,C)
  ↓
Block × N            # (B,T,C)
  ↓
final LayerNorm      # (B,T,C)
  ↓
lm_head              # (B,T,V)

That is already most of the architecture.

Common implementation bugs

Residual width mismatch

If attention returns (B,T,D) while the residual is (B,T,C), addition fails unless D=C. Multi-head attention therefore concatenates heads back to model width.

Future-token leakage

Every attention block must remain causal. A single missing mask changes the training problem.

Position length mismatch

If the input contains more positions than the positional table supports, the lookup fails. This is why context length is an architectural constraint.

Train/eval confusion

Dropout behaves differently during training and evaluation. Always switch modes explicitly when measuring the model.

Shape checkpoint

A well-designed block preserves (B,T,C) → (B,T,C). The attention sublayer temporarily uses head dimensions, the MLP temporarily expands to 4C, but both return to width C before residual addition.

A Transformer becomes less mysterious when you stop treating it as one invention and start treating it as a repeated composition of ordinary operations.
