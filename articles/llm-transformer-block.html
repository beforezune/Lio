Now assemble the machine: attention + MLP + residuals + normalization.

A GPT is not one giant mysterious operation. It is a stack of repeated blocks built from a small set of ordinary neural-network components.

Lio Learning Path · Intermediate

The modern decoder block

A common GPT-style pre-norm block can be written conceptually as:

x = x + Attention(LayerNorm(x))
x = x + MLP(LayerNorm(x))

The exact ordering varies across model families, but this pattern is an excellent educational baseline.

Layer normalization

LayerNorm normalizes features within each token representation, then learns a scale and bias. It helps keep activations in a manageable range as many blocks are composed.

self.ln1 = nn.LayerNorm(n_embd)
self.ln2 = nn.LayerNorm(n_embd)

The feed-forward network

The MLP works independently on each position after attention has mixed information. A simple version expands the channel dimension, applies a nonlinearity, then projects back.

self.mlp = nn.Sequential(
    nn.Linear(n_embd, 4 * n_embd),
    nn.GELU(),
    nn.Linear(4 * n_embd, n_embd),
    nn.Dropout(dropout),
)

Attention answers a routing question: “which information should this token read?” The MLP performs a learned transformation on the resulting representation. The two operations complement each other.

Residual connections

A residual connection adds the block's update to the existing representation instead of replacing it. This creates a direct path through the network and makes optimization of deep stacks much easier.

x = x + update

Think of each block as writing an additional correction into a shared stream of information. It does not need to rebuild the entire representation from zero.

One complete block

class Block(nn.Module):
    def __init__(self, n_embd, n_head, block_size, dropout=0.0):
        super().__init__()
        self.ln1 = nn.LayerNorm(n_embd)
        self.attn = MultiHeadAttention(n_embd, n_head, block_size, dropout)
        self.ln2 = nn.LayerNorm(n_embd)
        self.mlp = nn.Sequential(
            nn.Linear(n_embd, 4 * n_embd),
            nn.GELU(),
            nn.Linear(4 * n_embd, n_embd),
            nn.Dropout(dropout),
        )

    def forward(self, x):
        x = x + self.attn(self.ln1(x))
        x = x + self.mlp(self.ln2(x))
        return x

Stack the blocks

self.blocks = nn.ModuleList([
    Block(n_embd, n_head, block_size, dropout)
    for _ in range(n_layer)
])

for block in self.blocks:
    x = block(x)

Depth now becomes a simple hyperparameter. More blocks give the network more transformation capacity, but also increase memory and compute requirements.

Shape checkpoint

Every block should preserve the main shape: (B,T,C) → (B,T,C). If your attention or MLP changes C accidentally, the residual addition will expose the bug.

Final normalization and the language-model head

x = self.ln_f(x)
logits = self.lm_head(x)

If vocabulary size is V, logits have shape (B,T,V). For each position, the model produces one score for every possible next token.

The Transformer stack repeatedly refines a sequence representation. Attention mixes information; the MLP transforms it; residuals preserve a stable information highway.
